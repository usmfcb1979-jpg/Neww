# Soccer GM

A Python-based soccer management simulation game, inspired by Basketball GM. This project aims to create a detailed and realistic soccer management experience, from player stats and transfers to match simulation and tactical decisions.

## Current Status

This is the initial version of the project, featuring a basic, text-based simulation of a single league season.

## How to Run

To run the simulation, navigate to the `src` directory and execute the `main.py` script:

```bash
python3 src/main.py
```

This will set up a sample league, simulate a full season, and print the final standings to the console.
